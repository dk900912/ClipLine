## 品牌基调

| 项 | 设定 |
|---|---|
| 名称 | **ClipLine**（clip = 夹子 / 剪贴，line = 晾衣绳 / 一条线） |
| 一句话 | 截图挂起来，桌面就清爽了 |
| 气质 | 克制、轻、有秩序；Windows 11 Fluent 的几何感，不做 macOS 拟物金属 |
| 主色 | 靛蓝 `#4F5BD5` → 紫蓝 `#6C63F4` → 天青 `#2AA9E0`（绳 / 品牌色渐变） |
| 强调色 | 暖橙 `#F7BB5C` → `#EF8A24`（夹子，唯一的暖色点缀） |
| 中性色 | 上线 `#AEBBE4`、石墨 `#252A34`、雾白 `#F4F6FC` |
| 字标 | 西文 Segoe UI Variable / Semibold，字距 `-1%`；中文副标用等线/思源黑体，**不做产品名** |
| 网格 | 256×256，圆角方底 `r=56`，安全边距 24，最小可用尺寸 16×16（托盘图标） |

**统一约束**：主 Logo 必须能派生 **三态托盘图标**（默认 / 开启「挂上复制的图片」/ 空绳变暗）与 **单色、反白版**，并在 16 px 下仍可辨识。这是功能对齐清单里托盘行为带来的硬性要求，不是可选项。

## 正式 Logo · 方案 E「双线」Two Lines

**主文件**：`assets/logos/E-primary.svg`（256×256 正式主图标）
**原始概念稿**：`assets/logos/E-two-lines.svg`（保留存档，不再作为交付主图）

上面一条直线是刚产生的截图，下面一条下垂的线是挂上晾衣绳，中间一枚夹子把两者连起来。这是「从截图到晾挂」这个过程的最小抽象，也是五个方案里唯一把**产品动作**而非产品物件画进 Logo 的一个。

### 为什么它适合做主 Logo

- **Logo 就是产品动画**：直线缓缓坠成弧线，正是绳子从屏幕顶部滑下的展开动作，视觉与交互同源，不需要另外编一套品牌隐喻。
- **横向构图天然适配字标**：Windows 11 的标题栏、关于页、设置页页眉、安装向导都是横向版式，E 不用为这些场景另做变体。
- **极简到可以只用一色**：单色版、反白版、高对比度模式都不丢形；动态标识也能只靠一条路径的形变完成。
- **与产品里的绳同曲线**：下垂弧线沿用界面里的抛物线关系 `sag = min(30, width × 0.018)`，Logo 与界面是同一条线。

### 从「字标图形」升格为主图标要解决的三个问题

原评估里 E 的风险是「作为独立方形图标略显空」。定稿时通过以下处理消解，**不改变已选定的概念与识别特征**：

| 问题 | 处理 |
|---|---|
| 方形构图偏空 | 线条横向从 `36..220` 拉宽到 `24..232`，主弧线宽 9 → 12、上线宽 6 → 8、夹子 20×80 → 26×94，下垂控制点 `158 → 174`，让图形占满安全边距内的画面 |
| 16 px 下双线易与「列表/菜单」图标撞脸 | 出**独立像素对齐的 16 px 专用稿**：坐标取整、线宽 2 px、上线与弧线垂直间距 6 px，保留夹子作为第三识别特征；见下方尺寸阶梯规则 |
| 缺少状态表达 | 补齐三态托盘稿与单色/反白版，状态只靠线宽、饱和度、不透明度区分，**不加角标、不加红点**（避免与 Windows 通知徽章语义冲突） |

### 几何规格（`E-primary.svg`）

| 元素 | 参数 |
|---|---|
| 底板 | `256×256`，`rx=56`，`#FFFFFF → #EEF1FC` 竖向渐变，1 px `#E3E8F6` 描边 |
| 上线（原始截图） | `M24 78 H232`，`stroke-width=8`，`#AEBBE4`，圆头 |
| 下线（挂上绳） | `M24 120 Q128 174 232 120`，`stroke-width=12`，靛蓝→紫蓝→天青横向渐变，圆头 |
| 夹子 | `x=115 y=60 w=26 h=94 rx=11`，暖橙竖向渐变；两道白色高光条 |
| 坠点 | `cx=128 cy=170 r=8`，`#4F5BD5` |
| 安全边距 | 四边 24 u；字标锁排时图形与文字净空 ≥ 26 u（一个夹子宽） |

### 三态托盘图标

| 状态 | 文件 | 规则 |
|---|---|---|
| 默认 | `E-tray-16.svg` | 上线浅靛蓝、弧线主色、夹子暖橙；线宽 2 |
| 监听开启（绳上有图） | `E-tray-16-active.svg` | 上线转紫 `#8E7BF0`、弧线加粗 2.5 且转 `#6C63F4`、夹子加宽并填实心橙、中心加白色高光点 |
| 空绳变暗 | `E-tray-16-idle.svg` | 统一灰度、整体 `opacity=0.7` |

三态共用同一轮廓，切换时不会产生形状跳动；在浅色与深色任务栏上都要实测（预览页有深色任务栏对照）。

### 尺寸阶梯规则

| 尺寸 | 来源 | 说明 |
|---|---|---|
| 16 / 20 px | `E-tray-16*.svg` 专用稿 | 保留上线与弧线（小尺寸下这是核心识别特征），坐标全部对齐整像素、线宽 2 px；**省略坠点**。禁止直接缩小 256 稿 |
| 24 / 32 / 48 / 64 px | `E-primary.svg` 等比缩放 | 保留全部细节 |
| 256 px 及以上 | `E-primary.svg` | 应用图标、商店磁贴、关于页 |

落地时按 `docs/02-tech-stack.md` 的约定用 **Win2D / Composition 代码绘制**，构建期栅格化生成多分辨率 `.ico` 与 MSIX 图标资产，不把位图源文件打进安装包。

### 单色、反白与动态标识

- `E-mono.svg`：透明底纯 `#252A34`，靠线宽与 38% 明度区分上线与主线；把该色值全局替换为 `#FFFFFF` 即得反白版。用于高对比度模式、单色印刷、深色主题磁贴。
- `E-motion.svg`：直线 `Q128 78` → 弧线 `Q128 174` 的路径形变循环，夹子同步下移、坠点淡入。展开 `0.65 s` 缓出、停留 `0.9 s`、复位 `0.45 s`（SVG 演示稿为 3.2 s 循环便于观察）。与功能清单里 `0.65 s` 飞入动画、绳子滑下状态机同曲线，用于启动画面、加载态与「新图上线」提示。
- `wordmark.svg`：E 图形 + `ClipLine` + 中文副标的正式横向锁排，560×180。

## 五个方案的原始评估（存档）

### 方案 A ·「悬线」Sag & Clip

**文件**：`assets/logos/A-sag-and-clip.svg`

一根微微下垂的线，一枚夹子，一张玻璃相框照片。最直白地讲清「截图挂在线上」这件事，但不出现衣物、不出现多张晾晒的写实场景。线的弧度直接取自产品里的抛物线。

- **定位**：营销主视觉（官网 Hero、商店头图、README、安装向导、关于页）。
- **短板**：16 px 下夹子与卡内图形会糊，不适合做托盘。

### 方案 B ·「C 形绳」Monogram C

**文件**：`assets/logos/B-monogram-c.svg`

一根粗圆头笔画弯成字母 **C**，起笔处夹着一枚橙色小夹子，收笔处是一个圆点（绳结）。既是首字母，也是一段绳。

- **原评估**：曾推荐为主图标，小尺寸识别最强。
- **现定位**：**16 px 托盘图标的回退备选**。若 E 的专用稿在真机单屏高 DPI / 高对比度实测中辨识度不足，改用 B，无需改动其余资产体系。

### 方案 C ·「折角卡片」Folded Photo

**文件**：`assets/logos/C-folded-photo.svg`

短线 + 夹子 + 一张右上角折起的照片卡。方形构图饱满，贴近 Win11 磁贴语言。

- **现定位**：文件类型关联图标、右键扩展「挂到 ClipLine」入口。

### 方案 D ·「绳结」Knot

**文件**：`assets/logos/D-knot.svg`

一个绳环与一段交叉的绳尾构成结，下方垂出一张小卡片。呼应产品里分隔固定照片的那个绳结。

- **现定位**：品牌辅助图形、启动动画、周边；小尺寸需单独简化，不进托盘。

### 方案 E ·「双线」Two Lines — 已定稿

见上文「正式 Logo」章节。原评估中的优势（动态标识、横向锁排、单色可行）全部保留；「方形构图略空」已通过 `E-primary.svg` 解决。

| 用途 | 采用 |
|---|---|
| **正式 Logo / 应用图标 / exe·MSIX 图标 / favicon** | **E「双线」`E-primary.svg`** |

五个方案共用一套配色与 24 u 安全边距，主 Logo 与延展资产混用不会打架。

## 明确不要做

- ❌ T 恤、袜子、衣物、多件晾晒的写实晾衣绳 —— 原版图标与 README 插画的核心资产，避开。
- ❌ `Tendedero` 字样、相近字形、相近发音的中文名，以及任何「官方/原版/授权」暗示。
- ❌ 剪刀、虚线框、十字准星 —— 与 Windows 自带截图工具、Snipaste、ShareX 撞脸。
- ❌ macOS 拟物金属拉丝、厚投影、玻璃高光堆砌 —— 与 Windows 11 Fluent 的扁平几何不搭。
- ❌ 渐变文字、立体字、超过 3 种主色。
- ❌ 用角标、红点、数字表达托盘状态 —— 与系统通知语义冲突，且 16 px 下会糊。
- ❌ 把 256 稿直接缩小当 16 px 图标用。
