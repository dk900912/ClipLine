# ClipLine · Windows 11 UI 设计规范

> 本文是 **UI 视觉与交互的落地规格**，与 `01-feature-alignment.md` 的验收编号一一对应；几何与时序常量直接取自 v1.8.1 源码，不做「差不多」的改写。
>
> **状态（2026-11-04 用户确认）：已采纳**。本规范与配套原型为 v1 视觉与交互的**唯一基准**，实现阶段不得另起炉灶；如需偏离，先更新本规范并在工单里记录理由。综合实现规格已发布到 GitHub Issues（`ready-for-agent`）。
>
> **配套原型**：`assets/ui/prototype.html`（单文件、零外链、浏览器直接打开）。原型是视觉与交互演示，不是产品实现，差异见 §12。
> **范围**：v1 单显示器 + 单一系统缩放（见 `01` 的 `N-11`）。设计基准画布 1280×800，所有数值单位为 **DIP**（与原版 pt 一一对应）。

---

## 1. 设计定位

| 项 | 设定 |
|---|---|
| 产品形态 | **无主窗口、无任务栏按钮**的托盘常驻应用；主界面是屏幕顶部一条透明、点击穿透的「晾衣绳」 |
| 气质 | 克制、轻、有秩序；Windows 11 Fluent 的扁平几何，不做 macOS 拟物金属拉丝与厚投影 |
| 视觉锚点 | 一条抛物线与挂在上面的玻璃卡片；品牌 E「双线」Logo 的下垂弧线与界面里的绳同曲线 |
| 三条纪律 | ① 不遮挡、不抢焦点；② 只有卡片区域吃鼠标；③ 收起后不留任何窗口 |
| 与 macOS 的差异 | 原版 `ultraThinMaterial` → WinUI Acrylic / Win2D 自绘模糊；原版 `NSStatusItem` → `Shell_NotifyIconW` + `MenuFlyout`；系统 Markup / Quick Look / AVPlayerView → 自研窗口，见 §7 |

**配色**（沿用 `docs/04-brand-logo.md` 的 E 定稿）：

| 角色 | 浅色 | 深色 |
|---|---|---|
| 品牌渐变（绳 / 强调） | `#4F5BD5 → #6C63F4 → #2AA9E0` | 同色，降饱和 10% |
| 夹子暖橙 | `#F7BB5C → #EF8A24` | 同色 |
| 主要文字 | `#1B1B1F` | `#F3F4F8` |
| 次要文字 | `#5B606B` | `#B9BDC9` |
| 表面 / 二级表面 | `#FFFFFF` / `#F7F8FC` | `#2B2C33` / `#24252B` |
| 边框 | `rgba(0,0,0,.09)` | `rgba(255,255,255,.11)` |
| 玻璃卡片底 | `rgba(255,255,255,.70)` + blur 18 | `rgba(48,50,60,.66)` + blur 18 |
| 绳三层描边 | 阴影 `rgba(0,0,0,.22)` / 主体 `rgba(255,255,255,.62)` / 高光 `rgba(255,255,255,.48)` | 阴影 `.55` / 主体 `rgba(226,230,245,.62)` / 高光 `.42` |

> 绳是**中性灰白**，不是品牌渐变色；品牌渐变只用于 Logo、字标、进度/强调与动效，避免把绳染成彩色而破坏原版的轻盈感。

**排版**：`Segoe UI Variable`（西文）/ `Microsoft YaHei` 或等线（中文）；菜单与正文 12.5–13 DIP，徽标 11 DIP 半粗，空态 12 DIP 中粗，窗口标题 12 DIP Semibold；西文字距 `-1%`。**不**用渐变文字、立体字、超过 3 种主色。

**材质与形状**：卡片圆角 16（连续圆角）、照片圆角 12、菜单圆角 9、窗口圆角 10、胶囊 999；菜单/任务栏 `blur 30`，卡片 `blur 18`；阴影统一 0 5px 10px `rgba(0,0,0,.18)`（hover 0 8px 14px `.26`），窗口 0 22px 60px `.32`。

## 3. 主界面：晾衣绳

### 3.1 容器与绳（`V-01…V-10`）

| 元素 | 规格 |
|---|---|
| 条带 | 全屏宽、高 `panelHeight = photoMaxHeight + 106`（中档 **210** / 小 189 / 大 246）、透明、无边框、非激活、置顶、默认整窗鼠标穿透 |
| 命中 | 仅指针落在卡片命中矩形（外扩 4）时临时清除 `WS_EX_TRANSPARENT`；30 fps 追踪动态切换 |
| 绳曲线 | `sag = min(30, width × 0.018)`；`ropeY(x) = 10 + 4·sag·(x/w)·(1−x/w)`；`ropeTop = 10` |
| 三层描边 | 阴影 `black .22 / 1.4 / y+1.2 / blur 1.2`；主体 `white .55 / 1.2`；高光 `white .45 / 0.4 / y−0.35` |
| 端部 | 0→0.08 透明到实、0.92→1 实到透明的渐变遮罩 |
| 绳结 | 仅存在固定照片时：7×5.5 灰色椭圆 + 两条 1 pt 松散线头；位置在最后一张固定照片与下一张之间；固定照片在左、普通在右 |
| 销毁 | 收起 **0.3 s** 后 `DestroyWindow`，不留不可见顶层窗口 |

### 3.2 卡片（`V-11…V-20`）

| 元素 | 规格 |
|---|---|
| 尺寸档位 | 小 `0.8` / **中 `1`（默认）** / 大 `1.35`；`cardWidth = round(150×s)`、`photoMaxHeight = round(104×s)`、`spacing = cardWidth + 24`、`pinAbove = 9.5` |
| 玻璃相框 | 圆角 16、内边距 4、Acrylic、`上白 .55 → 下白 .12` 的 0.75 pt 渐变描边 + 0.5 pt 黑 .10 外描边；阴影 黑 .18 / 半径 10 / y5，hover 黑 .26 / 14 / y8 |
| 照片 | 按比例内嵌、圆角 `16−4 = 12`、0.5 pt 白 .18 内描边；缩略图上限 `320 × scale`（内存中每张只留一张） |
| 夹子 | 9×26、圆角 3.5、银色金属渐变（固定照片为深空灰），顶部 8.5 处 5×1.4 卡槽，阴影 黑 .30 / 2 / y1.5 |
| 倾斜 | 挂上时一次随机 `−2.5° … +2.5°`，之后不变 |
| 角标 | 左上 20×20 玻璃圆片、8 pt 粗符号、**命中区 26×26**、仅 hover 时 0.6→1 缩放淡入；符号随语义：`×`（回收站）/ `eye.slash`（仅下线）/ `pin.slash`（取消固定） |
| 「已复制」 | 11 pt 半粗胶囊徽标，**1.2 s** 消失 |
| 录屏 | `.mov/.mp4` 首帧 + 28×28 玻璃圆片播放键 |
| 空态 | 「截个图，它就会挂在这里」，12 pt 中粗胶囊材质，绳中点下方 34 |
| 淡影 | 「拿在手上」的卡片在绳上去饱和 + 0.3 透明度，点击即放回 |
| 边缘 | 靠近屏幕边缘渐隐 `min(x, width−x)/90`；越界卡片 0.35 透明度且不再响应点击 |

### 3.3 容量（`V-31`）

`visibleCount = clamp(3, 12, floor((屏宽 − 200) / spacing))`。设计基准 1280 DIP、中档 `spacing = 174` → `floor(1080/174) = 6`，正好是原型默认展示的 6 张。改尺寸档位后必须整体重算并重排。

## 4. 托盘图标与 16 项菜单（`T-01…T-07`）

**图标**：E「双线」定稿三态，`assets/logos/E-tray-16{,-active,-idle}.svg`。默认 / 开启「挂上复制的图片」（填充）/ 空绳变暗（灰度 0.7）。16/20 px 用专用像素对齐稿，24 px 以上等比缩放；不靠角标或红点表达状态。

**菜单视觉**：宽 246–262 DIP、圆角 9、Acrylic blur 30、行高 30、左右内边距 10、悬停 `rgba(79,91,213,.12)`；复选勾 14 宽、快捷键右对齐 11 DIP 次要色、子菜单箭头 `›`、禁用态 38% 不透明度；每次打开**重建**并逐项自报可用性。

**结构**（顺序不可变）：

| 序 | 项 | 类型 |
|---:|---|---|
| 1 | 显示 / 隐藏晾衣绳 `Ctrl+Alt+T` | 动态标题 |
| 2 | 全部取下 | `liveCount > 0` 才可用 |
| 3 | 挂回去 `Ctrl+Z` | `canPutBack` 才可用 |
| 4 | 全部放回绳上 | 仅有「拿在手上」时可用 |
| 5 / 6 | 接管截图 / 挂上复制的图片 | 复选（后者默认**关**） |
| 7 | 放下晾衣绳 ▸ | 3 复选子项：指针停在菜单栏时 **开** / 有新内容挂上时 **开** / 在全屏 App 上 **关** |
| 8 | 同时监视文件夹 ▸ | 已监视列表（≤3）、添加文件夹…、停止监视 ▸ |
| 9 / 10 | 绳上保留 ▸（放得下的数量 / 25 / 50 / 100）/ 大小 ▸（小 / 中 / 大） | 单选 |
| 11 | 快捷键 ▸ | 当前键（禁用项）、更改快捷键… |
| 12 | 打开截图文件夹 | — |
| — | 分隔符 | — |
| 13 / 14 / 15 | 声音 / 登录时打开 / 检查更新… | 复选 / 复选 / — |
| — | 分隔符 | — |
| 16 | 退出 ClipLine `Ctrl+Q` | — |

**「添加文件夹…」面板**：只能选目录、不可多选、主按钮文字「监视」、说明「保存到此文件夹的新图片会挂到晾衣绳上。」；路径去重、上限 3、无效路径自动剔除。每项 tooltip 例如「截图即刻挂上，不再经过桌面」「复制的图片也会挂上绳」。

## 5. 卡片右键菜单（`G-11…G-18`）

顺序：`复制` / `打开` / `快速查看` → （非录屏才有）`拿在手上` / `标记` → `在文件资源管理器中显示` → `固定` 或 `取消固定`（手动挂上的固定项不显示取消固定）→ （仅自有目录）`存储到桌面` → 分隔符 → `取下` / `丢弃` / `移到回收站`（按固定与目录条件组合）→ 分隔符 → `取下左侧全部` / `取下右侧全部`（无邻居时禁用）。**菜单打开期间线保持展开**。

## 6. 状态机 → 视觉映射（`S-01…S-11`）

| 状态 | 触发 | 视觉 |
|---|---|---|
| 收起 | 默认 | 条带 `translateY(-(panelHeight+12))`，`easeIn .22`；0.3 s 后销毁窗口 |
| 展开 | 顶部中间 1/3 热条停留 **0.25 s**（30 fps 追踪） | spring `response .42 / damping .82` 滑下 |
| peek | 新内容挂上 / 挂回去 | 自动展开 **2.5 s**，之后按常规收起 |
| 空绳 | 无卡片且非主动打开 | **0.7 s** 后自动隐藏；热区**不会**唤出空绳 |
| 主动展开 | 全局快捷键 / 菜单 | `pinned + keepOpen`，可覆盖全屏阻挡 |
| 压制 | 点击顶部栏任意处 | 立即收起并压制，直到指针离开顶部栏 |
| 不收起 | 拖拽中 / 菜单打开 / 卡片按下 / peek 未到期 | 保持展开 |
| 收起延迟 | 指针离开判定区 | **0.5 s**（判定区从线最低点延伸到屏幕顶） |
| 顶部热区 | 顶边 8–12 DIP 不可见热条，中间 1/3 | 任务栏置顶时改用任务栏空白中段并排除托盘/开始按钮 |

|---|---|---|---|

| 录屏修剪 | 最大 720×520，按视频比例 | 画面 + 修剪条（双手柄）+ 取消/修剪 | passthrough 无重编码，隐藏临时文件 `.trimming-<UUID>.<ext>`，完成后原子替换 |

## 8. 交互反馈矩阵（`G-01…G-10`）

| 手势 | 视觉反馈 |
|---|---|
| 悬停 | 放大 1.035 + 阴影加深 + 角标 0.6→1 淡入 |
| 按下 | 缩到 0.95，`easeInOut .45`（长按蓄力感） |
| 单击 | 复制；**延迟一个系统双击间隔**才执行；显示「已复制」1.2 s |
| 双击 | 系统默认应用打开 |
| 长按 0.45 s | 普通图 → 标注编辑器；录屏 → 修剪窗 |
| 角标点击 | 按语义执行；卡片走 0.55 s 下落动画 |
| 拖拽（阈值 4 pt） | 透明度 0.45、半透明拖拽预览；拖进应用=副本留绳，拖进文件夹=移动并下线，拖到回收站=应用自己删；取消/空放飞回原位 |
| 滚轮 | 长绳横向滚动，非精确滚动 ×12；新图入绳 `scroll = 0` |
| 键盘 | 指针在线内才临时借用 `Ctrl+Z` / 空格 / Delete，离开即注销，**焦点永不被绳抢走** |

## 9. 动效参数总表（`V-21…V-30`）

| 动效 | 参数 |
|---|---|
| 展开 / 收起 | spring `.42 / .82` / `easeIn .22`，位移 `-(panelHeight+12)` |
| 卡片增删 / 固定 | spring `.55 / .78`；空态切换 `easeInOut .3` |
| 新卡挂上 | 初始 16° 摆动，`stiffness 46 / damping 2.6` 归零，从 `y −46` 落位 |
| 飞入 | **0.65 s**、120 fps、`easeInOutCubic`、中途抬高 30 pt；玻璃框/夹子 0.35→1 渐显；最多 2 个并发 |
| 丢弃下落 | 向下 **520 pt**、`0.55 s` ease-in、角度 `tilt + (tilt×7+20)·e³`、渐隐 |
| 微风 | 每 7–16 s；逐卡随机延迟 0–0.35 s、1.6–3.4°、`easeOut .3` 出去 + `spring 38 / 2.4` 回来；拖动时不刮风 |
| 批量取下 | `0.06 s × n` 错开，只播第一声 |
| 丢弃后补位 | 最后一次丢弃 0.6 s 后且指针离开才 `closeGaps()` |
| 系统「减少动态效果」 | 关闭飞入、下落、微风；展开/收起改淡入淡出 |

## 10. 主题、缩放与无障碍

- **深浅色**：跟随 `UISettings` / `WM_SETTINGCHANGE("ImmersiveColorSet")`；绳的三层描边与玻璃框高光/阴影按主题重算，保证两种背景都可读。
- **高对比度**：关闭材质模糊，改系统色实边；夹子、角标、徽标必须仍可辨。
- **单一系统缩放**：布局常量按 DIP 存储，绘制乘 `GetDpiForWindow/96`；验收 100 / 125 / 150 / 200%。进程级 DPI 感知仍必须开启（见 `03` §1）。**v1 不做每屏 DPI 差异与显示器热插拔重排**。
- **UIA**：自绘卡片暴露 `Image` 角色与文件名，角标 `Button` 角色 + `Name`（「丢弃」「仅下线」「取消固定」），放回按钮 `Name = 放回绳上`；全部提供 `BoundingRectangle`；托盘图标描述含两行状态文案。
- **本地化**：11 种语言，菜单宽度按最长文案自适应（德语/葡语约 +30%），不截断、不用省略号。
- **隐私**：UI 里不出现任何账号、同步、上传字样；「检查更新…」只在点击时打开浏览器。

## 12. 原型的已知简化

`assets/ui/prototype.html` 用于评审视觉与交互，**不是实现代码**：

- 玻璃 / Acrylic / 阴影用 CSS `backdrop-filter` 近似；真实实现走 Win2D + Composition，绳的三层描边与端部渐变遮罩用 SVG 近似。
- 卡片里的「截图」是 CSS 绘制的示意图，不接真实文件、剪贴板或目录监听。
- 菜单用 DOM 生成，真实实现是 WinUI `MenuFlyout`（或退回 owner-draw `TrackPopupMenuEx`）。
- spring / 飞入 / 微风用 CSS 关键帧近似曲线，参数见 §9，实现时按该表精确复刻。
- 固定 1280×800 设计画布等比缩放展示；产品按单屏任意宽度 + 单一系统缩放运行。
- 力感应点按（`N-01`）无 Windows 物理等价，原型未演示；替代方案见 `03` §9。
